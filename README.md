# Student Management System

## Project Overview

The Student Management System is a simple and interactive web application developed using HTML, CSS, and JavaScript.

It allows users to manage student records through an easy-to-use interface.

## Features

- Add student records
- Edit student information
- Delete student records
- Search students
- Filter student records
- Sort students by marks
- Display student statistics
- Form validation
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts

This project demonstrates:

- Variables
- Functions
- Arrays
- Objects
- Conditional Statements
- Array Methods
- DOM Manipulation
- Events
